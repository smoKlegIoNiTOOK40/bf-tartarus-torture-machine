# Tartarus copy8

Windows PowerShell5.1/7, без сети и ML-пакетов. Модель4902байта, память8 слов,
30 слов словаря. Настоящие BF-кодирование/выбор/копирование/декодирование,
независимая BF-проверка и маленький отдельный архив каждого запроса.

    ./demo.ps1 -Prompt 'mira carries a red key who' -OutputDirectory ./runs/first
    ./demo.ps1 -Prompt 'what' -HistoryContextPath ./runs/first/final-history.context

Пути CLI разрешаются относительно текущей папки; сначала перейди в комплект.
История проверяется по полному манифесту предыдущего запуска и версии модели.
Новая беседа: запускай без HistoryContextPath. EOS не попадает в память.
Сначала явный факт и финальный who/what/where; короткий второй вопрос what/where
может использовать настоящий ответ. Это ограниченный язык фактов, не свободная
беседа. Незнакомые слова отвергает BF-кодек. Максимум98 строчных английских
символов с одиночными пробелами на ввод и7 вызовов модели на ответ.

24/24 validation и48/48 test, включая8/8 и16/16 связанных эпизодов; все
основные baseline хуже. Автор видел сырые отложенные данные. Полный протокол
и обучение доступны в отдельном исходном reproduction-комплекте.
Файлы источников общие, на каждый вопрос не копируются.
