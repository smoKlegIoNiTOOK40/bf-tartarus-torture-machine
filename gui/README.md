# Окно Tartarus

Открой `Tartarus.exe` в корне проекта. Резервный запуск — `Tartarus.cmd`.
Нужны Windows PowerShell5.1 и встроенный WPF; сеть и ML-пакеты не нужны.

По умолчанию выбран **Диалог · 8 слов**. Это обученная модель для маленького
мира фактов:30 слов словаря,8 последних слов памяти,4902байта параметров.

1. Выбери пример слева, например `mira carries a red key who`, и нажми
   **Спросить**. Модель ответит `mira`.
2. Нажми `what` и снова **Спросить**. Модель использует настоящий предыдущий
   ответ и отвечает `a red key`. Для примера с местом попробуй второй `where`.
3. Для другого факта выбери пример либо нажми **Новая беседа**. Это очищает
   память модели и окно; сохранённые файлы остаются.

Это ограниченный язык: сначала явный факт и финальное `who`, `what` или
`where`, затем короткий связанный вопрос. Свободная речь, произвольные
вопросы и длинная беседа пока не обучены. Кнопки второго вопроса показывают
доступные слова; подходящий вопрос зависит от факта. Доказанное качество:
24/24 validation и48/48 test, включая8/8 и16/16 связанных эпизодов.
Автор видел сырой отложенный корпус; протокол — `WORDQA8-COPY-RESULTS.md`.

В том же списке сохранены **Who v1 · вопросы** (отдельные ответы именем,
память4 слова) и два варианта **Word 80** для продолжения фразы. Их история
в окне не передаётся модели. Смена режима сбрасывает память диалога.

Ввод: максимум98 символов, строчные английские слова и одиночные пробелы.
Незнакомые слова отвергает BF-кодек. Ошибка или отмена не заменяет последнюю
успешную память. Если повреждены файлы памяти, начни новую беседу.

`Скопировать` копирует вопрос и ответ на отдельных строках. `Файлы запуска`
открывает сохранённый ввод, вывод и журналы. Каждый запрос получает свою
папку `gui/runs/session-…/gui-…`; общие исходники на запрос не копируются.
История проверяется по полному манифесту предыдущего успешного запуска и
версии модели. EOS исключён из памяти. Worker принадлежит окну; остановка
и закрытие завершают также его BF-процессы и сохраняют частичные файлы.

Интерфейс использует три общих зафиксированных пакета:

- `release/wordqa-copy8-v1` — диалог;
- `release/wordqa-who-v1` — прежние отдельные вопросы;
- `release/wordbackoff80-v1` — прежние продолжения.

Полные манифесты проверяются до и после генерации, каждый BF-источник —
перед первым использованием. Все арифметика модели, кодирование, выбор,
копирование слова, декодирование и независимые численные проверки выполняются
рукописным BF. Host обслуживает окно, файлы, байты и процессы.

Проверки разработчика: Windows PowerShell с `-NoProfile -STA -File`, затем
`gui/test-copy8.ps1`, `gui/test-who.ps1` либо `gui/test.ps1`. Они исполняют
настоящие модели и сохраняют отчёты/изображения в `gui/checks`. Предыдущая
версия окна сохранена в `gui/revisions/before-copy8-v1`.

Переносимый ZIP окна включает EXE, GUI и все три пакета; распакуй целиком
в новую папку. Отдельные CLI inference и полное обучение/оценка доступны
в самостоятельных ZIP. Обучению нужен PowerShell7, окну он не требуется.
Большая старая история сохранена в CAS: `tools/storage-v1/README.md`.
